Barberly Booking API · live examples

Book an appointment, two ways

The same guest booking flow — location, barber, services, time, confirmation — built twice on the Barberly Booking API. Both are open source and calling the real API as you read this.

The Booking API is one of the client-facing tools of a Barberly account, alongside the shop’s app, website and booking widgets. It books the way a client books: the catalog, the availability and the booking rules you will run into here are the ones the shop configured for its own booking page. These pages run against a demo shop with a public key, so everything you see is live and every booking is real. Book as often as you like; the data is disposable.
